# Reference data

Inputs shared by all benchmarks (solar model tables, measured spectra,
published P_ee and day-night points). Every file needs a sidecar
`<file>.yaml` with `source` (DOI/arXiv), `table_or_figure`, `retrieved`
(date), `method` (`table` | `digitised`) and `license`. Digitised values are
flagged as such in every plot that uses them.
